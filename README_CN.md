# 顿悟·拓展 Epiphany Extra

[English](README.md) | **简体中文**

「顿悟·拓展 Epiphany Extra」为「顿悟 Epiphany」模组增加了更多与第三方模组的联动，为其增加了更多的条件类型、奖励类型和阅历来源。

需要 Minecraft 1.21.1 的 NeoForge 与顿悟 Epiphany 作为前置。所有受支持模组均为可选依赖，只安装你需要的即可；未安装的模组只会关闭对应的联动。

## 已支持模组

| 模组                        | mod id            | 提供内容             |
|-----------------------------|-------------------|----------------------|
| 起源 Origins                | `origins`         | 条件、奖励、阅历来源 |
| 起源：职业 Origins: Classes | `origins_classes` | 条件、奖励、阅历来源 |
| Oritech                     | `oritech`         | 条件                 |
| 新生魔艺 Ars Nouveau        | `ars_nouveau`     | 条件                 |
| 潮汐 Tide                   | `tide`            | 条件                 |
| Reskillable Reimagined      | `reskillable`     | 条件、奖励           |
| ViScriptTeam                | `viscript_team`   | 条件、奖励           |
| ViScriptQuests              | `viscript_quests` | 条件、奖励、阅历来源 |
| Field Guide                 | `fieldguide`      | 条件                 |
